## Project Overview

The BandR IT Consultants website is a fully responsive, professionally built corporate website created over a two-month development period. The final product delivers a dark-themed interface enhanced with gradient visuals, glassmorphism effects, and a clean corporate layout. The site showcases the company’s services, brand identity, and leadership in a structured and modern design system.

This website demonstrates:

- A modern corporate UI/UX system  
- Full responsiveness across all devices  
- Clean and organised front-end code  
- Optimised loading performance  
- Intuitive navigation and structured content delivery  

---

## Technologies Used

- **HTML5**  
- **CSS3** (dark theme, gradients, glassmorphism, responsive layout)  
- **JavaScript** (navigation, UI interactions)  

No heavy frameworks or libraries were used, ensuring fast performance and lightweight deployment.
